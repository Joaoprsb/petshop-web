# 🐾 PetShop Amicão

Projeto desenvolvido para a disciplina de **Fundamentos de Sistemas Web**.

## 📖 Sobre o projeto

O PetShop Amicão é uma plataforma web desenvolvida para apresentar os produtos e serviços oferecidos por um petshop.

Nesta primeira fase do projeto foi utilizada apenas a linguagem **HTML**, sem a utilização de CSS, Bootstrap ou JavaScript, conforme os requisitos da disciplina.

## ✨ Funcionalidades

- Página inicial com apresentação do petshop;
- Catálogo de produtos dividido em categorias;
- Página de serviços oferecidos;
- Página de contato;
- Página de ajuda descrevendo as funcionalidades do sistema.

## 🛍️ Produtos

O sistema apresenta produtos das seguintes categorias:

- Acessórios
- Rações
- Higiene e limpeza

Cada produto possui:

- Imagem;
- Nome;
- Descrição;
- Valor.

## 🐶 Serviços

O petshop oferece os seguintes serviços:

- Banho;
- Banho com tele-busca;
- Banho e tosa;
- Banho e tosa com tele-busca.

Cada serviço apresenta:

- Descrição;
- Valor;
- Informação sobre tele-busca.

## 🛠️ Tecnologias utilizadas

- HTML5

petshop-web/

## 🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em qualquer navegador.
